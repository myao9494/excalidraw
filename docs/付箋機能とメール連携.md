# 付箋機能とメール連携ガイド

このドキュメントでは、Excalidrawに追加された付箋作成機能とメールドラッグ・アンド・ドロップ機能について説明します。

## 📌 付箋作成機能

### 基本的な付箋作成

**ショートカット**: `N`キー

- キーボードの`N`を押すと、カーソル位置に黄色い付箋が作成されます
- 付箋サイズ: 200x150ピクセル
- 付箋の中央がカーソル位置に配置されます

### リンク付き付箋作成

**ショートカット**: `W`キー

- キーボードの`W`を押すと、クリップボードのリンクが付いた付箋が作成されます
- クリップボードにHTTPSで始まるURLがある場合、自動的に付箋にリンクが設定されます
- リンクがない場合は通常の付箋として作成されます

### 付箋の特徴

- **色**: 黄色 (#fef3c7)
- **サイズ**: 200x150ピクセル
- **枠線**: 黒色、2px幅
- **形状**: 角の丸くない長方形
- **クリック可能**: リンクが設定されている場合はクリックでリンク先に移動

## 📧 メールドラッグ・アンド・ドロップ機能

### 対応メールクライアント

#### ✅ 完全対応
- **macOS Mail.app**: すべての機能が動作
- **Thunderbird**: メール情報の完全な取得

#### ⚠️ 部分対応
- **Outlook (Mac/Windows)**: 基本機能は動作するが、一部制限あり
- **Gmail (ブラウザ)**: プレーンテキストとしての取得

### 使用方法

1. **メールを選択**: 任意のメールクライアントでメールを選択
2. **ドラッグ開始**: メールをドラッグしてExcalidrawキャンバスに移動
3. **ドロップ**: 希望する位置でマウスボタンを離す
4. **自動処理**: 
   - 付箋が作成される
   - メールの件名が付箋内に表示される
   - メールファイルが保存される
   - 付箋にメールファイルへのリンクが設定される

### メール保存機能

#### File System Access API対応ブラウザ (Chrome, Edge)

1. **初回のみ**: フォルダ選択ダイアログが表示
2. **フォルダ選択**: メールを保存したいフォルダを選択
3. **自動フォルダ作成**: 選択フォルダ内に`mail/`フォルダが自動作成
4. **メール保存**: EML形式でメールが保存される
5. **ファイル名**: `件名_タイムスタンプ.eml`形式

#### その他のブラウザ (Firefox, Safari)

- 自動ダウンロード機能が動作
- メールファイルがDownloadsフォルダに保存される

### メールファイル形式

**保存形式**: RFC822準拠のEMLファイル
```
From: sender@example.com
To: recipient@example.com
Subject: メールの件名
Date: Mon, 7 Jan 2025 12:34:56 +0900

メール本文がここに含まれます...
```

## 🔧 技術仕様

### 付箋作成のアクション

- **アクション名**: `createNote`, `createNoteWithLink`
- **ファイル**: `packages/excalidraw/actions/actionCreateNote.tsx`
- **ローカライゼーション**: 英語・日本語対応

### メール解析機能

#### 対応データ形式

| MIME Type | 説明 | 対応状況 |
|-----------|------|----------|
| `com.apple.mail.PasteboardTypeEmailMessage` | macOS Mail.app | ✅ 完全対応 |
| `text/x-moz-message` | Thunderbird | ✅ 完全対応 |
| `com.microsoft.outlook.message` | Outlook for Mac | ⚠️ 部分対応 |
| `application/x-ms-outlook` | Outlook for Windows | ⚠️ 部分対応 |
| `text/html` | HTML形式メール | ✅ 対応 |
| `text/plain` | プレーンテキスト | ✅ 対応 |
| `message/rfc822` | EMLファイル | ✅ 対応 |

### ファイル構造

```
packages/excalidraw/
├── actions/
│   ├── actionCreateNote.tsx          # N キー付箋作成

│   ├── types.ts                      # アクション型定義
│   └── shortcuts.ts                  # キーボードショートカット
├── utils/
│   ├── emailUtils.ts                 # メール解析・保存
│   └── mailFolderManager.ts          # フォルダ管理
```

## 🐛 トラブルシューティング

### メールが認識されない場合

1. **デバッグ情報の確認**:
   - ブラウザの開発者ツール (F12) を開く
   - Consoleタブを選択
   - メールをドラッグ・アンド・ドロップ
   - 「利用可能なデータタイプ」の情報を確認

2. **対処法**:
   - 異なるメールクライアントを試す
   - メールを.emlファイルとして保存してからドラッグ
   - プレーンテキストとしてコピー&ペースト

### フォルダ選択ができない場合

1. **ブラウザ確認**: Chrome または Edge を使用
2. **権限確認**: ブラウザにファイルアクセス権限があることを確認
3. **フォールバック**: 自動ダウンロード機能が動作

### 付箋が作成されない場合

1. **キーボードフォーカス**: Excalidrawキャンバスにフォーカスがあることを確認
2. **ショートカット確認**: 他のアプリケーションがキーを使用していないか確認
3. **ブラウザリロード**: ページを再読み込み

## 🎯 使用例

### ワークフロー例: プロジェクト管理

1. **企画メール受信** → メールをドラッグ・アンド・ドロップ → 企画エリアに付箋配置
2. **要求仕様メール** → リンク付き付箋でスペックドキュメントに直接リンク
3. **進捗報告** → 完了した付箋を別エリアに移動

### 使用例: 会議準備

1. **議事録メール** → 付箋として配置
2. **資料リンク** → `W`キーでクリップボードのリンクを付箋に
3. **アクションアイテム** → `N`キーで新規付箋作成

## 📊 パフォーマンス

- **付箋作成**: 即座に実行 (< 100ms)
- **メール解析**: 平均 200-500ms
- **ファイル保存**: ブラウザ・ファイルサイズに依存
- **メモリ使用**: メール1通あたり約1-5MB
