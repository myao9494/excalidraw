# Quick Start: Sticky Notes & Email Integration

## 🚀 すぐに始める

### 付箋を作成する

1. **基本の付箋**: キーボードの `N` を押す
2. **リンク付き付箋**: 
   - URLをクリップボードにコピー
   - キーボードの `W` を押す

### メールを付箋にする

1. **メールを選択**: メールクライアントでメールを選択
2. **ドラッグ**: メールをExcalidrawキャンバスにドラッグ
3. **ドロップ**: 希望する位置でドロップ
4. **完了**: 件名付きの付箋が作成され、メールファイルが保存される

## ⚡ 3分で理解する機能

### 付箋作成のショートカット

| キー | 機能 | 説明 |
|------|------|------|
| `N` | 基本付箋 | カーソル位置に黄色い付箋を作成 |
| `W` | リンク付箋 | クリップボードのURLを付箋にリンク |

### メール対応状況

| メールクライアント | 対応レベル | 注意事項 |
|-------------------|------------|----------|
| macOS Mail | ✅ 完全対応 | すべての機能が動作 |
| Thunderbird | ✅ 完全対応 | メール情報を完全に取得 |
| Outlook | ⚠️ 部分対応 | 基本機能のみ |
| Gmail (Web) | ⚠️ 限定対応 | テキストのみ |

### ファイル保存の仕組み

```
選択したフォルダ/
└── mail/                    # 自動作成
    ├── 会議議事録_2025-01-07T10-30-00.eml
    ├── プロジェクト要件_2025-01-07T14-15-30.eml
    └── 進捗報告_2025-01-07T16-45-00.eml
```

## 🎯 実践的な使い方

### シナリオ1: プロジェクト管理

```
1. プロジェクトキックオフメール → ドラッグ&ドロップ
2. 要件定義書のURL → クリップボードにコピー → W キー
3. 新しいタスク → N キーで付箋作成
```

### シナリオ2: 会議準備

```
1. 議事録メール → ドラッグ&ドロップで付箋化
2. 資料リンク → W キーでリンク付箋
3. アクションアイテム → N キーで新規付箋
```

### シナリオ3: 情報整理

```
1. 重要メールを付箋として配置
2. 関連リンクをW キーで追加
3. カテゴリごとにグループ化
```

## 🔧 トラブル時の対処

### 付箋が作成されない

- Excalidrawキャンバスをクリックしてフォーカスを当てる
- 他のアプリがキーボードショートカットを使用していないか確認

### メールが認識されない

- ブラウザの開発者ツール (F12) でConsoleを確認
- 異なるメールクライアントを試す
- メールを.emlファイルとして保存してからドラッグ

### ファイルが保存されない

- Chrome または Edge ブラウザを使用
- ディレクトリ選択ダイアログで適切なフォルダを選択
- ブラウザの権限設定を確認
