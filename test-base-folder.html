Base Folder URL パラメータ テスト

使用方法

URLパラメータに baseFolder を指定することで、ファイルの基準ディレクトリを設定できます。

基本的な使用例

http://localhost:3000?baseFolder=/Users/sudoupousei/000_work/web_file_manager/excalidraw_myao

フォルダとファイルを同時に指定

http://localhost:3000?baseFolder=/Users/sudoupousei/000_work/web_file_manager/excalidraw_myao&folder=test&file=sample.excalidraw

完全なファイルパスを指定

Unix/macOS:

http://localhost:3000?filepath=/Users/sudoupousei/000_work/web_file_manager/excalidraw_myao/sample.excalidraw

Windows:

http://localhost:3000?filepath=C:\Users\sudoupousei\000_work\web_file_manager\excalidraw_myao\sample.excalidraw

日本語パス (Windows):

http://localhost:3000?filepath=C:\Users\田中太郎\ドキュメント\図面\設計書.excalidraw

日本語パス (macOS):

http://localhost:3000?filepath=/Users/田中太郎/デスクトップ/プロジェクト/図面.excalidraw

動作確認

上記のリンクをクリックすると、指定したベースフォルダを基準にしてファイルシステムが動作します。

開発者コンソールでネットワークタブを確認すると、base_folder パラメータが API リクエストに含まれていることが確認できます。

API 呼び出し例

ファイル一覧取得

GET /api/v1/files/?base_folder=/Users/sudoupousei/000_work/web_file_manager/excalidraw_myao

ファイル保存

POST /api/v1/files/save/?base_folder=/Users/sudoupousei/000_work/web_file_manager/excalidraw_myao
